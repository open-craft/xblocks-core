# Games XBlock

Migrated from https://github.com/edx/gamesxblock.

This is a temporary README, to be replaced with an official guide on https://docs.openedx.org/en/latest/.

Some notes about the Games XBlock:

- To enable in Studio, add "games" to the course's Advanced Settings list.
- There is a waffle flag "legacy_studio.enable_games_xblock" which appears to be ignored these days.
- The Studio editor for this block is implemented in [frontend-app-authoring](https://github.com/openedx/frontend-app-authoring/tree/master/src/editors/containers/GamesEditor).
